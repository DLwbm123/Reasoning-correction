# 固定自然轨迹队列：第二批文本复核规则

目的：检查未被模型reasoning/inference标签提名的原始字符串及其他kind中是否仍有可定位的推断问题，避免模型自标kind成为错误筛选器。本批只做既有自然轨迹的盲文本初筛，不增加模型调用、医学真值或效用实验。

从已经冻结的100例顺序中排除已初筛的4例，取余下前12例；不读取闭合参考或正确性记录后选样，不换样或补足缺失内容。先保存12个身份及顺序，再打开对应blind包，原100队列、原包和首批记录均不改写。只读取这12包，不重新提取/扫描100例或G2原数据，不重新打开首批4例。

每例记录是否有可见推断、涉及哪个阶段、原声明与登记观察的对象/限定语/模态是否相符、最终选择是否与自身明确判别陈述对应。初筛类别允许并存：text_conflict（同一对象/范围的显式文字冲突）、support_gap_candidate（连接依据/判别或观察覆盖缺口）、answer_mapping_candidate（自身陈述与所选标签不符）、no_text_support_conflict_identified、insufficient_trace。逐例必须注明原始片段和推断，不凭词相似度或程序SUPPORTED判定；不得将先后更新或不同范围误标为逻辑矛盾。

图像前提真假、知识真假和医学因果均保持unadjudicated；登记观察未提及某事实不证明图像不支持。外显缺口不能认证内部推理错误，文本初筛不是独立专家真值；闭合答案本批不展示、不追加对错分层。复用分支不作为独立事件，混合问题类别也不以同一患者累加统计。保留无冲突和无法判定的对照。

只报告完整12例的完成/缺失、类别病例计数和未知；不从12例估总体错误率、不重称未见测试、不据本批结果训练或调阈值。逐例内容/身份/引用全部私有，只公开规则与汇总。沿用本队列原17:45:25.113截止，届时保留已完成记录并结束，不为同一准备延长时钟；预计少量文本新增<100KB，不启动CPU/GPU后台任务。
