# G9：多区域临床源标签的自然初稿修订诊断

在模型首次调用前冻结。既有32例、选择规则、失败记录与原时钟见PREPARATION.md；不修改已完成G1–G8。本轮不训练模型、gate或表征，不提供临床安全保证，不把区域源一致性当自由解释/临床因果真值。

## 对象、阶段和隔离

仅用已冻结的官方train 32研究/32患者，每例两个有框、无progression且类别不相交的阳性源发现。全部32及所有失败保留，不按模型事件补样。64个finding集合有参考，56个location集合有参考；8个位置缺失不作阴性或空集合真值。源参考含模型提取/翻译/分类与医师质控/定位的不同环节，零新增专家裁决。

阶段固定为：CPU解码/显示图登记→全部32初稿→initial_done锁定→首次打开updates.private→6种修订/确定复制控制→collection_done锁定→独立CPU程序首次打开labels.private一次评价。初稿只读manifest及全train词表，另一未释放区域的参考不入修订DTO。研究者和程序已用源注释作资格/清单准备，本池为开发性诊断，不称未见临床测试。源患者与官方heldout不交，不证明与旧PMC/预训练无重叠。

图像统一为原PNG完整像素解码，要求二维非负整数且范围≤65535；按本图真实min/max线性映射、round到uint8，再RGB转换，保方向不翻转、不自动反色，最大边1024的LANCZOS缩放；叠加r1红/r2蓝官方框及逻辑ID。框为各条件共享额外标注输入，多框不称多病灶。常量/不可解码图保留unavailable，不造对比度或换样本。记录原尺寸/模式/dtype/min/max/显示尺寸/实际文件，模型再用既有Qwen处理器min_pixels256×28²、max_pixels768×28²。显示图是预处理输入，不是新增医学观察。

## 自然初稿与具体输出

复用当地只读Qwen2.5-VL-7B-Instruct、既有同一模型缓存，不更新依赖/权重。bf16、sdpa、全参数冻结、greedy、num_beams1。每调用fresh messages，调用间不共享KV或assistant历史。输入硬上限8192tokens，不截断。

原始输出包含values和parents，固定五槽：r1.finding/r1.location/r2.finding/r2.location的精确词表字符串集合，加answer短摘要；parents只引用槽ID、不可循环，属于模型提议而非充分临床规则。空集合表示未决，不表示不存在。初稿最多1024输出tokens；摘要独立医学语义未裁决，不计临床正确率。不注入人工错误，空/错/正确/格式失败均保留。

初稿结构解析一次，无包装/补字段/格式重试。失败保留原文和可解析原对象，不编成一个新原答案或claim ledger。所有32初稿有记录后才释放每例预定一个区域的源句和源类别/位置；它是受控提供的数据集review信息，不是新自动Observer或新专家就诊结论。目标种子、16/16分布不因初稿表现改动。

## 六条件与无模型强控制

每例条件顺序用seed2026110816+索引洗牌；修订各最多1536输出tokens、一次调用、无格式重试。各条件同显示图/区域/词表/初稿来源/释放的同一条源记录；差异如下，不能一概叫完全相同消息。

| 条件 | 行为与信息差异 |
|---|---|
| full_recompute | 同信息fresh完整重算；初稿和其候选图均可见，作为未验证提议 |
| evidence_summary | 同信息source表格的重复表示；仍可见同一原提议，不额外观察/调用摘要器 |
| local_edit | 通用局部编辑偏好；允许重看全图并改其他明确错误，不人为限制能力 |
| patch_no_graph | 显式不可变差分；原父边清空，属于图信息消融 |
| patch_graph | 显式不可变差分；可见原候选父边，同full/local共享候选图信息 |
| old_quarantine | 仅目标槽与已释放标签一致者被程序登记为source-supported，其余unknown并做后继闭包；隔离原文字，属旧规则的表示控制，不叫G2原始模型复现 |

另有确定复制控制：把已释放的目标标签放入目标槽，其余原值复制；目标位置缺标注则保持原值。它不看其他参考，也不推其他原值正确。原初稿无效时仍可输出已释放目标槽，其余null，不故意削弱此强控制。目标修复来自输入本身，不能包装成方法创新；关键还看非目标错误修复与正确事实保持的权衡。

不可变差分用独立assertion_revision接口。KEEP精确复制，REPLACE新ID，WITHHOLD保留未知/冲突；本五槽任务不接受ADD。tag槽text是JSON编码数组，answer是短摘要。模型选择已有evidence_id/span_id，程序只按实际登记span绑定quote/Unicode区间，不补语义；image_registry仅是实际显示图指针，不是文字医学观察，其relation只可UNREVIEWED。所有关系仍model_proposal、semantic_eligible=false，不用其自报支持认证解释或部署接受。

初稿无合法ledger时patch两条件记录不可用，不伪造ledger；full/summary/local/quarantine四条件在图像可用时仍可从图+释放记录重新生成，避免削弱强对照。不可用图片无模型生成且保留全部分母。上限32+6×32=224次，实际可因图片/初稿失败减少；无另外测速/试采样/重启追格式门槛。首个实际初稿同时作为无评价标签的执行绑定检查，不重复生成。

## 评价、失败与推断范围

仅全部32×6有终态记录后打开离线标签。每条件同时报告原始候选源一致性，以及整候选格式失败时明确COPY原结果的schema-fallback结果；WITHHOLD/空集合另记未决，不将“没断言”与断言错误混为一谈。所有方法32分母；未完整则不报成功幸存者成绩。

source-exact为规范化标签集合相等，不是对自由医学语言做字符串蕴含。源标签一致率micro分母120槽，并给每患者3或4槽的均值。目标source-disagreement修复、其中非空错误与未决分别统计；非目标原正确槽的错误/丢失分开，非目标原错额外修复另报。逻辑集合变化与仅数组顺序/序列化变化分开。缺位置只报告覆盖，原始类别/位置/格式/摘要原文均保存。

摘要真实性、源句语义限定全部准确性、临床充分支持边、模型内部因果均无独立裁决，不给这些指标造0/1真值。公开全部条件和负结果；不挑最好条件/图/种子改prompt。32患者的配对patient-mean差及2000次bootstrap(seed2026110817)仅描述性，未多重校正；图内槽与条件不当独立患者。确定可计算的聚合不当新医学推理贡献。
