## 预注册接口目标

- 42 个请求的 public tests 全部获得可登记观察：42/42（100%），达到 ≥90% 目标。
- 初始终端格式失败 0/32，达到 ≤1/32 目标。
- 全部 238 次调用均通过相应格式解析，无重试、执行绑定失败或整例管线异常。

这里的登记成功指字段、单次执行来源和 test 对应关系可用，不证明观察内容正确。
四例没有 public test，因此“42/42”不能改写成所有病例均被充分观察。
模型自评 adequate 的病例为 27/32；没有专家/oracle 观察，也没有过程正确性金标准。

## 机制结果

Selective、Reset、Random-drop 和 Evidence-summary 在全部 32 例上给出相同最终答案，
不是仅准确率相等。21/32（65.625%）的 K 为空；11 例 K 非空也未改变这些条件的答案。
共 41 条有效初始 claims，其中 34 条 visual、6 条 knowledge、1 条 reasoning；7 条有父节点。
图闭包相对 flat filter 改变 K 的次数仍为 0。
Binder 产生 SUPPORTED 18、UNRESOLVED 22、CONTRADICTED 1 个判断，冲突触发仅 1 例。

Selective minus Reset 的样本配对 bootstrap 区间为 [0,0]，原因是本样本所有配对差异为 0，
不是对任意分布等效的证明。Selective minus Raw 为 -3.125 pp，区间 [-12.5,+6.25] pp。
32 例是接口试验，不能支持小差异的性能结论。

接口修复达到了计划目标，仍未建立当前短 VQA 设置中的状态保留价值。由于样本、提示接口、
软件栈都不同，不能把本次与 E0 的准确率差解释成接口修复的因果效果。

## 计算及下一步

238 次生成、16,850 次语言 forward；输入 159,981 tokens，图像 tokens 73,747，
输出 16,850 tokens。单调用延迟 p50=1.73 秒、p95=3.12 秒。
峰值 GPU allocated 17.14 GB、reserved 20.29 GB。已有权重只读复用，项目保守统计约 16.61 GB。
入口和 GPU 显示保持中性，未终止或修改其他进程。

不扩大到 5,000 条门控训练、不加入 RL、不将接口修复包装为最终方法贡献。
现在需要区分：自动观察不够有区分力，还是即使证据正确，当前任务也没有需要选择性重建的
上下文干扰。先核对 Contextual Drag、Premise over Pixels、MedFH 和 MirageCheck 的相关机制，
再用可核验标注提供的 oracle 条件建立必要的受控诊断。Oracle 若直接揭示答案，必须单列说明，
不得作为部署性能、自然纠错率或临床有效性的证据。
